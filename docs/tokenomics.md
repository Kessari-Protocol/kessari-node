# Tokenomics

This document describes the economic model of the Kessari protocol.

## Native Token

The native token is used for:

- Transaction fees
- Validator staking and slashing
- Governance participation

## Supply

Details of the token supply schedule, inflation rate, and distribution will be
published prior to mainnet launch.

## Fees

Transaction fees are burned or redistributed to validators according to protocol
parameters defined in the on-chain governance module.

> **Note**: Core economic enforcement modules are not included in this public
> repository during early development.
